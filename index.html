Crea un modulo di sondaggio

Crea un'app che sia funzionalmente simile a questo progetto di esempio. Cerca di non copiare il progetto, dagli il tuo stile personale.

Obiettivo: Completa le storie utente qui sotto e fai passare tutti i test per completare il laboratorio.

Storie utente:

  1. Dovresti avere un titolo della pagina in un elemento h1 con un id di title.
  2. Dovresti avere una breve spiegazione in un elemento p con un id di description.
  3. Dovresti avere un elemento form con un id di survey-form.
  4. All'interno dell'elemento modulo dovresti avere un campo input obbligatorio per inserire il tuo nome che ha un id di name e un type di text.
  5. All'interno dell'elemento modulo dovresti avere un campo input obbligatorio per inserire la tua email che ha un id di email.
  6. Se inserisci un'email non formattata correttamente, dovresti vedere un errore di validazione HTML5.
  7. All'interno dell'elemento modulo dovresti avere un campo input per inserire un numero che ha un id di number.
  8. L'input numerico non dovrebbe accettare valori non numerici, sia impedendoti di digitarli sia mostrando un errore di validazione HTML5 (a seconda del browser).
  9. Se inserisci numeri fuori dall'intervallo definito dagli attributi min e max del campo numerico, dovresti vedere un errore di validazione HTML5.
  10. Per i campi di input nome, email e numero, dovresti avere elementi label corrispondenti nel modulo, che descrivono lo scopo di ogni campo con gli id: name-label, email-label e number-label.
  11. Per i campi di input nome, email e numero, dovresti avere un testo segnaposto che fornisce una descrizione o istruzioni per ogni campo.
  12. All'interno dell'elemento modulo, dovresti avere un menu a discesa select con un id di dropdown e almeno due opzioni tra cui scegliere.
  13. All'interno dell'elemento modulo, puoi selezionare un'opzione da un gruppo di almeno due pulsanti di opzione raggruppati usando l'attributo name.
  14. All'interno dell'elemento modulo, puoi selezionare più campi da una serie di caselle di spunta, ognuna delle quali deve avere un attributo value.
  15. All'interno dell'elemento modulo, dovresti avere un textarea per commenti aggiuntivi.
  16. All'interno dell'elemento modulo, dovresti avere un pulsante con id di submit per inviare tutti gli input.
